# 시간표 작성기

교사·과목·시수·회피 시간을 입력하면 **학급별 시간표를 자동으로 배치**하는 웹앱.
백엔드가 없고, 입력한 내용은 브라우저(localStorage)에만 남는다.

## 입력

| 탭 | 내용 |
| --- | --- |
| 시간 설정 | 수업 요일, 1교시~마지막 교시의 시작·종료 시각, 점심·쉬는시간 칸 |
| 학급·특별실 | 학급 목록(`1-1 ~ 1-10` 일괄 생성), 과학실·음악실 등 특별실 |
| 교사 | 교사 목록(여러 명 붙여넣기), 교사별 회피 요일·교시 격자 |
| 담당 배정 | 교사 × 과목 × 학급 × 주당 시수 × 연속 2교시 블록 수 × 특별실 |

## 지키는 제약

항상 지켜지는 것 (배치 구조상 깨질 수 없음)

- 한 학급은 한 교시에 한 수업만
- 연속 2교시 블록은 붙어 있는 두 교시에만 (점심·쉬는시간 칸을 넘지 않음)

0으로 몰아가는 것

- 한 교사가 같은 교시에 두 학급에 들어가지 않음
- 교사 회피 시간에는 배정하지 않음
- 같은 학급의 같은 과목은 하루 한 번만 (블록은 한 번으로 셈)
- 같은 특별실을 같은 교시에 두 수업이 쓰지 않음

제한 시간 안에 전부 해소하지 못하면 **충돌 없는 시간표 + 미배치 목록**을 돌려주고,
각 미배치 건마다 "교사 회피 시간 7칸 / 교사가 다른 학급 수업 중 5칸" 식으로 막힌 이유를 센다.

## 배치 엔진

`src/solver.ts` — min-conflicts 국소 탐색.

1. 학급마다 격자에 초기 배치 (블록 먼저, 같은 과목은 다른 요일로)
2. 충돌에 얽힌 수업을 골라 자기 학급 안의 다른 자리로 이동
   자리 주인은 밀어내고 비용이 가장 낮은 빈칸으로 다시 넣는다(퇴출 이동 = 자리 맞바꾸기)
3. 평지에 갇히면 최선 해로 되돌린 뒤 몇 수를 무작위로 흔들고, 오래 못 벗어나면 완전히 새로 시작
4. 시간이 끝나면 남은 충돌에 가장 많이 얽힌 수업부터 빼내어 충돌 0으로 정리

Web Worker(`src/solver.worker.ts`)에서 돌아 화면이 멈추지 않는다.

### 성능 (Node, 참고값)

| 규모 | 결과 |
| --- | --- |
| 4학급 · 교사 10명 · 학급당 35/35시간 | 3ms, 완전 배치 |
| 30학급 · 교사 55명 · 학급당 34/35시간 | 15ms, 완전 배치 |
| 30학급 · 학급당 35/35시간(빈칸 0) | 18ms, 완전 배치 |
| 30학급 · 교사마다 하루 전체 회피 | 1.0s, 완전 배치 |

```bash
npm run bench    # 예시 데이터 + 하드 제약 검증
npm run stress   # 30학급 규모 부하 테스트 (HARD=1, EXTRA=1 로 난이도 상향)
```

npm install
